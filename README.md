# Stationery & Food Lister

Expo + React Native + TypeScript foundation for a local-first Stationery & Food Lister app.

## Stack

- Expo + Expo Router
- React Native + TypeScript (strict)
- React Native Reanimated + Gesture Handler + Expo Haptics
- Zustand
- TanStack Query
- Expo SQLite
- Lucide React Native

## Run

```bash
npm install
npx expo start
```

Web preview:

```bash
npx expo start --web
```
